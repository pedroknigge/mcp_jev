# Publish mcp_jev

This project does **not** publish to npm. The public line is GitHub Releases.

See [RELEASES.md](RELEASES.md) for versioning (starts at `0.0.9`, bump one path, roll at 99) and how to cut a tag.

Install and update from GitHub: `scripts/install.sh` then `scripts/update.sh`. Do not `npm publish` from a PR, a tag, or a laptop.
